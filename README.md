# CIS11-The-Assemblers
The Assemblers group project option B: Test Score Calculator 
## Team Members
- Miguel: Code and Pseudocode
- Josh: Documentation
- Cole: Code and Pseudocode
## Description
This LC-3 program asks the user to enter 5 test scores. The program calculates and displays the minimum score, maximum score, average score, and letter grade.
## Required Test Values
52, 87, 96, 79, 61
## Expected Output
- Minimum: 52
- Maximum: 96
- Average: 75
- Letter Grade: C

- `Pseudocode/` = project Pseudocode
